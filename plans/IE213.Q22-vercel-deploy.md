## Required Vercel Environment Variables

Set these in Vercel Project Settings > Environment Variables:

```env
MONGODB_URI=mongodb://USER:PASSWORD@HOST:27017/intelligentroutex?authSource=admin
MONGODB_DB_NAME=intelligentroutex
AUTH_SECRET=<32+ chars random secret>
NEXTAUTH_SECRET=<same as AUTH_SECRET or another 32+ chars secret>
NEXTAUTH_URL=https://your-domain.vercel.app
AUTH_URL=https://your-domain.vercel.app
NEXT_PUBLIC_APP_URL=https://your-domain.vercel.app
TOKEN_ENCRYPTION_KEY=<64 hex chars if token encryption routes are used>
ADMIN_SECRET_KEY=<admin secret>
ADMIN_STEALTH_TOKEN=<admin route token>
```

## MongoDB Hosting Requirement

Vercel cannot connect to `localhost` MongoDB. Use one of these:

- A VPS-hosted MongoDB with firewall allowing Vercel outbound access.
- A managed MongoDB-compatible provider that is not Atlas if Atlas is not desired.
- A private backend/database service with a public connection endpoint or VPN/tunnel strategy.

For self-hosted MongoDB:

- Enable authentication.
- Do not expose `27017` broadly without firewall/IP allowlist.
- Enable scheduled backups.
- Use a non-root app user with access only to `intelligentroutex`.
- Prefer TLS for public internet connections.

## Deploy Steps

1. Push branch `IE213.Q22`.
2. Set Vercel env vars above for Preview and Production.
3. Ensure external MongoDB is reachable from Vercel.
4. Run Vercel preview deployment.
5. Smoke test:
   - `GET /api/health`
   - `GET /api/public/products`
   - `GET /api/public/categories`
   - register/login with credentials
   - `GET /api/profile`
   - `PUT /api/profile`
6. Only promote to Production after smoke tests pass.
