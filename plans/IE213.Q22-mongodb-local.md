# IE213.Q22 - MongoDB Local/Self-Hosted

Dự án không dùng MongoDB Atlas cho branch `IE213.Q22`. Môi trường mặc định là MongoDB chạy local bằng Docker Compose; production/staging có thể dùng MongoDB self-hosted hoặc dịch vụ MongoDB khác miễn cung cấp URI chuẩn.

## Chạy MongoDB local

```powershell
docker compose -f docker-compose.mongodb.yml up -d
```

URI local:

```env
MONGODB_URI=mongodb://miniver:miniver_dev_password@localhost:27017/intelligentroutex?authSource=admin
MONGODB_DB_NAME=intelligentroutex
MONGODB_TEST_URI=mongodb://miniver:miniver_dev_password@localhost:27017/intelligentroutex_test?authSource=admin
```

## Tạo collections/indexes

```powershell
npx -y mongosh@latest "mongodb://miniver:miniver_dev_password@localhost:27017/intelligentroutex?authSource=admin" scripts/mongodb/create-schema.js
```

## Kiểm tra kết nối

```powershell
npx -y mongosh@latest "mongodb://miniver:miniver_dev_password@localhost:27017/intelligentroutex?authSource=admin" --quiet --eval "db.runCommand({ ping: 1 })"
```

## MCP MongoDB local

Codex MCP nên trỏ về local URI:

```powershell
[Environment]::SetEnvironmentVariable(
  "MDB_MCP_CONNECTION_STRING",
  "mongodb://miniver:miniver_dev_password@localhost:27017/intelligentroutex?authSource=admin",
  "User"
)
```

Sau đó restart Codex CLI để MCP load lại.

## Production không dùng Atlas

Các lựa chọn phù hợp:

- VPS tự host MongoDB bằng Docker, bật auth, firewall, backup định kỳ.
- Render/railway/fly.io hoặc provider khác nếu có MongoDB-compatible service.
- MongoDB replica set tự quản nếu cần transaction/HA nghiêm túc.

Không expose port `27017` public nếu không có firewall/IP allowlist/VPN.
