Chốt hệ thống cho bạn như này:

1 hệ thống, 1 lõi tính thật, 2 chế độ in

Lõi bắt buộc: dùng slicer thật để tính
	•	FDM: grams, support grams, print time từ G-code
	•	Resin: resin volume/support volume và print time từ mSLA slicing output

Không dùng AI để đoán mấy số này.

Lý do rất đơn giản: code hiện tại của bạn đang suy grams / hours / price từ volume và vài hằng số tay ở frontend, nên sai nhiều là đúng bản chất, không phải lỗi nhỏ  ￼  ￼  ￼.

⸻

Hệ thống mình chốt

Slicer chính: PrusaSlicer CLI

Mình chốt PrusaSlicer CLI làm lõi cho cả 2 loại in vì:
	•	nhận STL/OBJ/AMF
	•	xuất G-code cho FFF
	•	xuất PNG layers cho mSLA
	•	có CLI đầy đủ
	•	hỗ trợ support material, raft, brim, skirt
	•	chạy multithread  ￼

Slicer phụ: CuraEngine chỉ cho FDM nếu cần

CuraEngine cũng là console app để sinh G-code, chạy độc lập được và pipeline của nó đúng kiểu slicer thật: load model → slice layers → insets → skins → infill → G-code  ￼.
Nhưng để hệ thống gọn, mình khuyên bản đầu chỉ dùng PrusaSlicer.

Chốt cách làm cho FDM

FDM exact quote flow
	1.	User upload STL/OBJ/3MF
	2.	Hệ thống hash file
	3.	Parse nhanh:
	•	bbox
	•	preview
	4.	Worker gọi PrusaSlicer CLI với:
	•	printer profile
	•	filament profile
	•	layer height
	•	infill
	•	support on/off
	•	nozzle
	•	brim/raft/skirt
	5.	Slicer sinh G-code
	6.	Parser đọc metadata/G-code:
	•	filament used
	•	support material
	•	print time
	•	layer count
	7.	Price engine tính giá

FDM output chuẩn

{
  "mode": "fdm",
  "bboxMm": { "x": 72, "y": 58, "z": 110 },
  "mainMaterialG": 38.4,
  "supportMaterialG": 11.2,
  "totalMaterialG": 49.6,
  "printTimeMinutes": 327,
  "layerCount": 550,
  "source": "prusaslicer_exact",
  "price": 189000
}

FDM giá tính như sau

price
= main_material_cost
+ support_material_cost
+ machine_time_cost
+ postprocess_cost
+ packaging_cost
+ waste/risk_cost
+ margin

Chốt cách làm cho Resin

Resin exact quote flow
	1.	User upload STL/OBJ/3MF
	2.	Parse nhanh:
	•	bbox
	•	preview
	3.	Worker gọi PrusaSlicer mSLA profile
	4.	Slicer sinh PNG layers
	5.	Từ sliced layers + support geometry, hệ thống tính:
	•	main resin volume
	•	support resin volume
	•	total resin ml/g
	•	print time theo profile máy
	6.	Price engine tính giá

Resin cần nói thật

Với resin, cái bạn lấy được là:
	•	material estimate theo slicer
	•	time estimate theo slicer/profile

Nó là cách đúng nhất trong phạm vi phần mềm, nhưng vẫn là “mức slicer”, không phải lượng resin hao hụt thực tế trong vat sau mỗi job.
Dù vậy, đây vẫn là đúng hướng nhất nếu bạn muốn “chính xác như slicer”.

AI nên dùng ở đâu để vừa free vừa hữu ích

AI 1 — Orientation ranking

Đây là AI đáng làm nhất.

Nhiệm vụ

Từ mesh:
	•	bbox
	•	overhang proxy
	•	support risk
	•	height/width ratio

AI/rule engine chọn ra 2–3 orientation tốt nhất thay vì brute-force nhiều góc.

Lợi ích
	•	nhanh hơn
	•	vẫn chính xác vì cuối cùng slicer vẫn chạy thật
	•	giảm support/time

AI 2 — Risk detection

Phát hiện:
	•	model dễ gãy
	•	support quá nhiều
	•	base nhỏ, dễ đổ
	•	thin walls
	•	mesh lỗi

Output
	•	low / medium / high risk
	•	warning list
	•	recommendation

AI 3 — Preset recommendation

AI gợi ý:
	•	FDM hay resin
	•	layer height nên dùng
	•	infill phù hợp
	•	support strategy

Ví dụ
	•	tượng nhiều chi tiết nhỏ → resin 0.05
	•	model lớn, ít detail → FDM 0.2

AI 4 — Quote explanation

Sinh giải thích:
	•	giá cao vì support nhiều
	•	thời gian dài vì model cao và layer nhỏ
	•	resin đắt hơn do support + wash/cure

⸻

Giá nên tính như nào

FDM

material_cost = main_g * main_price_per_g
support_cost  = support_g * support_price_per_g
machine_cost  = print_time_h * machine_rate_per_h
post_cost     = support_remove + cleanup + labor
packaging     = fixed
risk_margin   = fixed or %
final_price   = subtotal + margin

Resin

material_cost = total_resin_g * resin_price_per_g
machine_cost  = print_time_h * machine_rate_per_h
post_cost     = wash + cure + support remove + finishing
packaging     = fixed
risk_margin   = fixed or %
final_price   = subtotal + margin
